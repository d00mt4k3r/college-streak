# College Streak

College Streak помогает следить за посещаемостью, заданиями и учебной серией.

## Возможности

- отмечать посещение каждой пары;
- вести расписание и список предметов;
- записывать задания;
- просматривать календарь и статистику;
- получать достижения за регулярную учебу.

## Как работает серия

- все пары посещены — серия увеличивается;
- пропущена хотя бы одна пара — серия сбрасывается;
- больничный не изменяет серию;
- выходной или праздник не учитывается.

## Приватность

Приложение работает офлайн. Данные хранятся только на устройстве и не
отправляются на сервер. Регистрация и интернет не требуются.
