# College Streak — трекер посещаемости и заданий

Простое личное приложение на React Native + Expo. Все данные хранятся только
на телефоне (AsyncStorage), без сервера, аккаунтов и интернета.

## Структура проекта

```
college-streak/
├── app/                      ← экраны (Expo Router: путь файла = маршрут)
│   ├── _layout.js            ← корневая навигация (Stack)
│   ├── onboarding.js         ← первый запуск
│   ├── (tabs)/               ← нижняя навигация
│   │   ├── _layout.js
│   │   ├── index.js          ← Главная (стрик, пары на сегодня)
│   │   ├── tasks.js          ← Предметы и задания
│   │   ├── calendar.js       ← Календарь
│   │   └── stats.js          ← Статистика и достижения
│   ├── schedule/
│   │   ├── index.js          ← режим расписания (один шаблон / чередование)
│   │   ├── templates.js      ← список шаблонов недель
│   │   └── template-detail.js← редактирование пар внутри шаблона
```

## Как устроена логика стрика (важно для понимания кода)

Все данные хранятся одним JSON-объектом в AsyncStorage (`src/storage/storage.js`).
Ключевая идея — **день "закрывается" автоматически**, когда отмечены все его пары:

- если все пары отмечены ✅ — стрик увеличивается на 1, день зелёный;
- если хотя бы одна пара отмечена ❌ — стрик сбрасывается до 0, день красный;
- 🏥 больничный — день "замораживается": стрик не растёт и не обнуляется;
- 🎉 выходной/праздник — день просто не учитывается вообще.

Если нужно исправить уже закрытый день (например, ошибся вчера) — в календаре
есть кнопка "Сбросить и редактировать заново". Она аккуратно отменяет то, что
этот день уже сделал со статистикой, и даёт отметить всё заново. Это специально
самый простой вариант логики (без пересчёта всей истории целиком) — он много
проще в поддержке и покрывает все жизненные ситуации из задания.

Подробные комментарии — прямо в `src/logic/streakLogic.js`.

## 1. Установка зависимостей

Понадобится Node.js (версия 18 или новее) и npm. Проверить, что установлено:

```bash
node -v
npm -v
```

В папке проекта выполнить:

```bash
cd college-streak
npm install
```

## 2. Запуск приложения на телефоне (без сборки APK)

Самый быстрый способ проверить приложение в процессе разработки:

1. Установи на телефон приложение **Expo Go** (из Google Play).
2. В папке проекта запусти:
   ```bash
   npx expo start
   ```
3. Появится QR-код в терминале/браузере. Отсканируй его камерой телефона
   (Android: прямо через приложение Expo Go → "Scan QR code").
4. Телефон и компьютер должны быть в одной Wi-Fi сети.

Так можно быстро проверять изменения в коде — они применяются почти мгновенно.

## 3. Сборка APK-файла (чтобы установить приложение "по-настоящему")

Для сборки используется сервис EAS (Expo Application Services) — он бесплатный
для личных проектов такого размера.

1. Установи EAS CLI (один раз):
   ```bash
   npm install -g eas-cli
   ```
2. Зарегистрируйся / войди в аккаунт Expo (бесплатно, нужен только для сборки,
   на работу самого приложения никак не влияет и данные пользователя не трогает):
   ```bash
   eas login
   ```
3. Запусти сборку APK:
   ```bash
   eas build --platform android --profile preview
   ```
4. Первый раз EAS спросит про параметры проекта — просто соглашайся со
   значениями по умолчанию (Enter). Сборка идёт на серверах Expo, обычно
   5–15 минут.

## 4. Где будет готовый APK

После окончания сборки в терминале появится **ссылка на скачивание APK**
(и она же будет доступна в личном кабинете на https://expo.dev в разделе Builds).
Скачай файл `.apk` по этой ссылке на телефон или на компьютер.

## 5. Как установить APK на Android

Если скачал на компьютер — перекинь файл `.apk` на телефон (по USB, через
Telegram "Избранное", Google Диск и т.д.), затем:

1. Открой файл `.apk` на телефоне (через Проводник/Файлы).
2. Android спросит разрешение "Установить неизвестное приложение" — разреши
   для того приложения, через которое открываешь файл (например, для
   Файлов/Chrome). Это стандартное предупреждение Android для APK не из
   Google Play, беспокоиться не о чем — приложение полностью твоё.
3. Нажми "Установить".
4. Готово — иконка появится на рабочем столе, приложение работает офлайн.

## Первый запуск

При первом открытии приложение проведёт через короткую настройку:
добавление предметов и (по желанию) настройку расписания. Всё это можно
изменить позже через значок ⚙️ на главном экране.

## Если что-то хочется доработать самостоятельно

- Цвета и отступы — `src/constants/theme.js`.
- Тексты и эмодзи — прямо в файлах экранов (`app/...`), они читаемые.
- Вся логика стрика и достижений — `src/logic/`, там больше всего комментариев.
- Структура хранимых данных — `createEmptyData()` в `src/storage/storage.js`.

Проект специально не использует сложные библиотеки (drag-and-drop, сложные
навигационные графы и т.п.) — только то, что нужно, чтобы код было легко
читать и менять самостоятельно.
